📌 Giới thiệu Tổng quan về MyEMS

MyEMS là hệ thống quản lý năng lượng (Energy Management System - EMS) mã nguồn mở tham chiếu tiêu chuẩn quốc tế ISO 50001 (tương đương chuẩn GB/T 23331-2020 của Trung Quốc). Hệ thống được thiết kế chuyên biệt để thu thập, làm sạch, chuẩn hóa, phân tích và báo cáo dữ liệu năng lượng cũng như phát thải carbon.

🏢 Đối Tượng Áp Dụng Ứng dụng

Tòa nhà thương mại, nhà máy sản xuất, trung tâm thương mại, bệnh viện, khu công nghiệp, trung tâm dữ liệu và trung tâm quản lý năng lượng / carbon cấp tập đoàn.

💡 Các Loại Năng Lượng Đa dạng

Hỗ trợ thu thập & giám sát Điện năng, Nước, Khí nén / Gas, Năng lượng làm lạnh (Chilled Water), Nhiệt năng, Hơi nước và các dạng năng lượng tái tạo.

🌿 Quản Lý Carbon & Tái Tạo Mới

Hỗ trợ Điện mặt trời (PV), Lưu trữ năng lượng (ESS), Trạm sạc EV, Lưới điện vi mô (Microgrid), Nhà máy điện ảo (VPP) và Tối ưu hóa bằng AI.

🏗️ Kiến trúc Hệ thống MyEMS

MyEMS tuân thủ kiến trúc microservices hiện đại, tách biệt hoàn toàn giữa các tầng IoT Data Acquisition, Data Processing Engine, RESTful API, Multi-Database Layer và Frontend User Interfaces.

📐 Các Tầng Trong Kiến Trúc Tổng Thể

1. Edge / IoT Acquisition Layer

Các dịch vụ chạy dưới background thu thập dữ liệu chuỗi thời gian từ đồng hồ/cảm biến qua Modbus TCP, BACnet, Siemens S7, MQTT...

2. Data Processing Pipeline

Dòng dữ liệu đi qua chuỗi làm sạch (Cleaning) → chuẩn hóa (Normalization) → tính toán tổng hợp (Aggregation: chi phí, phát thải carbon, FDD).

3. Multi-Database Storage Layer

Phân tách 13 cơ sở dữ liệu riêng biệt theo chức năng để tối ưu hóa hiệu năng đọc/ghi và khả năng mở rộng theo chiều ngang (Horizontal Scaling).

4. Application & Presentation Layer

Cung cấp RESTful API qua Python Falcon, kết hợp cùng Web User Interface (ReactJS) và Admin Panel (AngularJS).

🧩 Chi Tiết Các Thành Phần Vi Dịch Vụ (Microservices)

🖥️ myems-web ReactJS

Giao diện người dùng chính dành cho nhân viên vận hành và quản lý. Hiển thị báo cáo năng lượng, biểu đồ thời gian thực, dashboard lớn (Large Screen), phân tích chi phí và lượng phát thải CO2.

⚙️ myems-admin AngularJS

Giao diện quản trị hệ thống. Cho phép cấu hình sơ đồ cây không gian (Spaces), quản lý thiết bị (Equipments), đồng hồ (Meters), điểm đo (Points), quy tắc FDD và phân quyền người dùng.

🔌 myems-api Python + Falcon

Dịch vụ RESTful API hiệu năng cao chạy trên khung làm việc Falcon (gunicorn/waitress). Đóng vai trò là cầu nối giữa các cơ sở dữ liệu và hai giao diện web người dùng/quản trị.

📡 Services Thu Thập Dữ Liệu IoT Acquisition

Bao gồm myems-modbus-tcp, myems-bacnet, myems-s7. Tự động đọc dữ liệu định kỳ từ thiết bị ngoại vi và ghi trực tiếp vào cơ sở dữ liệu lịch sử myems_historical_db.

🧹 myems-cleaning Data Cleaning

Dịch vụ làm sạch dữ liệu. Kiểm tra các giá trị bất thường, giá trị bị thiếu (missing/bad data), loại bỏ nhiễu và đánh cờ chất lượng dữ liệu trước khi chuyển sang bước chuẩn hóa.

📐 myems-normalization & myems-aggregation Data Engine

Normalization: Chuyển đổi dữ liệu thô thành chỉ số tiêu thụ theo từng giờ.
Aggregation: Tổng hợp mức tiêu thụ, tính toán tiền điện theo biểu giá (Tariff), phát thải carbon (CO2) và phát hiện sự cố (FDD).

🗄️ Kiến trúc 13 Cơ Sở Dữ Liệu Tách Biệt (Multi-Database)

MyEMS sử dụng nguyên tắc Data Separation Architecture (tách biệt dữ liệu). Điều này giúp tránh tình trạng một database duy nhất bị phình to, đảm bảo hiệu năng tối ưu cho các truy vấn thời gian thực và lịch sử.

Tên Cơ Sở Dữ Liệu Mục Đích Sử Dụng Quy Mô Dữ Liệu Bảng Nổi Bật
myems_system_db Lưu cấu hình hệ thống, thiết bị, đồng hồ, cây không gian, biểu giá, công ty Trung bình (~150+ bảng) tbl_meters, tbl_equipments, tbl_spaces, tbl_points
myems_historical_db Lưu dữ liệu đo chuỗi thời gian thực (Analog, Digital, Energy, Text) & file upload Rất lớn tbl_analog_value, tbl_digital_value, tbl_energy_value
myems_energy_db Lưu thống kê tiêu thụ năng lượng theo giờ/ngày/tháng/năm của meter & không gian Rất lớn tbl_meter_hourly, tbl_space_input_category_hourly
myems_billing_db Lưu dữ liệu chi phí năng lượng đã quy đổi ra tiền (CNY/USD/VND) theo biểu giá Rất lớn tbl_meter_hourly, tbl_equipment_input_category_hourly
myems_carbon_db Lưu dữ liệu lượng phát thải khí nhà kính (kgCO2e) tính theo hệ số phát thải Rất lớn Cấu trúc tương tự myems_energy_db
myems_fdd_db Lưu quy tắc chẩn đoán lỗi (Fault Detection & Diagnosis) và lịch sử cảnh báo Trung bình tbl_rules, tbl_web_messages, tbl_email_messages
myems_user_db Lưu thông tin người dùng, mật khẩu mã hóa, phiên làm việc (Session), API Keys, Audit Logs Nhỏ tbl_users, tbl_privileges, tbl_api_keys, tbl_logs
myems_energy_baseline_db Dữ liệu đường cơ sở năng lượng phục vụ phân tích tiết kiệm năng lượng Trung bình Bảng baseline theo giờ của các đối tượng
myems_energy_model_db Mô hình tiêu thụ năng lượng 8760 giờ trong năm (8760 hours model) Trung bình tbl_meter_8760, tbl_space_input_category_8760
myems_energy_plan_db Lưu kế hoạch và mục tiêu tiêu thụ năng lượng đặt ra Trung bình Bảng kế hoạch tiêu thụ theo đối tượng
myems_energy_prediction_db Dữ liệu dự báo tiêu thụ năng lượng từ các thuật toán ML/AI Trung bình Bảng dự báo tiêu thụ
myems_reporting_db Cấu hình và lưu trữ báo cáo nâng cao (Advanced Reports: Excel, PDF, Word) Nhỏ tbl_reports, tbl_reports_files, tbl_template_files
myems_production_db Dữ liệu sản lượng sản xuất (sản phẩm, ca làm việc, xưởng) để tính chỉ số suất tiêu hao Nhỏ tbl_products, tbl_shifts, tbl_shopfloor_hourly

🔄 Quy Trình Luồng Dữ Liệu (Data Flow)

1. Luồng Thu Thập & Xử Lý Dữ Liệu (Data Pipeline)

Bước 1
IoT Edge / Smart Meters: Đồng hồ thông minh, cảm biến gửi tín hiệu điện/nước/gas qua công nghiệp.
↓ Modbus TCP / BACnet / Siemens S7 / MQTT
Bước 2
Acquisition Services (myems-modbus-tcp...): Đọc dữ liệu điểm đo (Points) và ghi vào myems_historical_db (các bảng tbl_analog_value, tbl_digital_value).
↓ Raw Data
Bước 3
myems-cleaning: Lọc dữ liệu lỗi, phát hiện bất thường, đánh cờ is_bad và điền bù dữ liệu bị thiếu.
↓ Cleaned Data
Bước 4
myems-normalization: Tính toán tích lũy chênh lệch điểm đo để ra lượng tiêu thụ theo giờ của Meter, ghi vào myems_energy_db.tbl_meter_hourly.
↓ Hourly Energy Data
Bước 5
myems-aggregation: Tổng hợp dữ liệu lên cấp Không gian (Space), Thiết bị (Equipment), Cửa hàng (Store), Bên thuê (Tenant). Tính toán tiền theo Biểu giá (Tariff) vào myems_billing_db, tính lượng CO2 vào myems_carbon_db và chạy quy tắc cảnh báo FDD vào myems_fdd_db.

2. Luồng Truy Vấn & Hiển Thị Dữ Liệu (Data Query Flow)

Trình duyệt người dùng (Web UI) → Gửi REST HTTP Request tới myems-api (Port 8000) → API kiểm tra xác thực người dùng từ myems_user_db → API đọc cấu hình từ myems_system_db & truy vấn số liệu từ myems_energy_db / myems_billing_db / myems_carbon_db → Trả kết quả JSON cho Frontend vẽ đồ thị.

🔑 Cấu Hình Mặc Định (Default Ports & Credentials)

🌐 Số Cổng Dịch Vụ (Default Ports)
  • 🔹 MyEMS Web UI: Cổng 80
  • 🔹 MyEMS API Service: Cổng 8000
  • 🔹 MyEMS Admin UI: Cổng 8001
  • 🔹 MySQL / MariaDB: Cổng 3306

🔐 Tài Khoản Đăng Nhập Mặc Định

Áp dụng cho cả Giao diện Admin UI (Port 8001) và Web UI (Port 80):

Tên đăng nhập (Username): administrator
Mật khẩu (Password): !MyEMS1

🚀 Hướng Dẫn Triển Khai & Cài Đặt

1. Chạy Thử Nhanh myems-api Trên Windows (Development)

# 1. Cài đặt Python 3.10 / 3.11 / 3.12
# 2. Cài đặt các thư viện phụ thuộc:
cd myems/myems-api
pip install -r requirements.txt
pip install waitress

# 3. Khởi chạy API server với Waitress trên cổng 8000:
waitress-serve --listen=0.0.0.0:8000 app:api

2. Chạy Giao Diện myems-web Trong Môi Trường Phát Triển

# Cài đặt các package Node.js
cd myems/myems-web
npm install

# Khởi chạy server phát triển local tại http://localhost:3000
npm start

# Đóng gói sản phẩm sản xuất (Production Build)
npm run build

3. Triển Khai Sản Xuất Khuyên Dùng (Docker / Linux Server)

Trong môi trường sản xuất chính thức, khuyên dùng Docker Compose hoặc triển khai Linux (Ubuntu/Debian) với Nginx làm Reverse Proxy, Gunicorn chạy myems-api và systemd daemonize các background microservices.
